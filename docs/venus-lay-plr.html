Investigation and test plan · Venus layouts and PyLabRobot

Converting Venus .lay layouts to and from PLR decks

The placement and sequence rules a converter needs, measured on 152 real layouts, and a test plan that runs both round trips without Venus.

Placement, stacking, sequences: measured Lid Z: open 15 October 2026

Summary

  1. Layouts can be read without Venus. A small binary reader matches Hamilton's own converter on all 150 binary layouts in the test set. The converter itself is best avoided: it sends a keystroke to whatever window has focus.
  2. Carriers: deck site {w}T-{rail} sits at X = 100 + (rail − 1) × 22.5, Y 63, Z 100, PLR's track_to_location. Exact for all 1,071 carriers on rails.
  3. Racks: Venus stores well A1, at corner + (BndryX, BndryY + (Rows − 1) × Dy). The rack's corner sits on the carrier site's corner in 3,747 of 3,830 placements (97.8%); the rest are hand nudges.
  4. Z: with ZTransValue 0 or 1 a rack sits at the site's Z (96%). ZTransValue 2 means Z was set by hand. That is the "+1 mm" in STAR_OEM_Test.lay.
  5. Stacking: the next rack up sits at the lower rack's Z plus the lower rack's StackHt, with no exceptions in 524 stacks.
  6. Default sequences: one per rack with DefSeqValid 1, named after the rack, listing every position column-major. Wells are named A1… or numbered down the columns, according to IX.Index.
  7. Open: lid Z. Lids are always named <plate>_lid and centred on the plate, but their height follows no rule found yet.

Reading without Venus

The binary form is simple. A header (u16 version, u16, u32 section count) is followed, for each section, by its name, a u16 version, a u32 entry count and the key/value strings. Each string has a one-byte length, or 0xFF followed by a two-byte length. Some files are stored as text already; those start with HxCfgFile.

CheckResult

Avoid HxCfgFilConverter.exe for bulk work. After converting, it calls Windows SendKeys, which types into whatever window has focus. Run in parallel or without a desktop session, it crashes with “Access is denied”. The reader below needs no Venus at all, so it also runs in ordinary CI.

hxbin.py
"""Reader for Hamilton HxCfgFile files in their binary ("packed") form, no Venus tools needed.

Layout, as observed:
  u16 file version, u16 ?, u32 section count
  per section:  str "TYPE,NAME", u16 section version, u32 entry count, entries
  dict entries: str key, str value
  str:          u8 length, or 0xFF followed by u16 length, then latin-1 bytes
After the sections comes the "* $$author=...$$" footer.
Only dictionary sections ({ key, "value" } in text form) are decoded; HxPars list sections (.med) are not.
"""
import struct


class Reader:
  def __init__(self, data: bytes):
    self.d = data
    self.i = 0

  def u8(self):
    v = self.d[self.i]
    self.i += 1
    return v

  def u16(self):
    v = struct.unpack_from("<H", self.d, self.i)[0]
    self.i += 2
    return v

  def u32(self):
    v = struct.unpack_from("<I", self.d, self.i)[0]
    self.i += 4
    return v

  def s(self):
    n = self.u8()
    if n == 0xFF:
      n = self.u16()
    v = self.d[self.i:self.i + n].decode("latin-1")
    self.i += n
    return v


def read_binary(path):
  """Return {(type, name): {key: value}} like hxcfg.read_sections, for a binary file."""
  r = Reader(open(path, "rb").read())
  r.u16()
  r.u16()
  count = r.u32()
  sections = {}
  for _ in range(count):
    header = r.s()
    typ, _, name = header.partition(",")
    r.u16()
    n = r.u32()
    kv = {}
    for _ in range(n):
      k = r.s()
      kv[k] = r.s()
    # later sections with the same (type, name) are kept separately, as in text form
    key = (typ, name)
    while key in sections:
      key = (typ, name + "#")
    sections[key] = kv
  return sections

Default sequences

Existing sequences are not carried over: real layouts contain broken, stale and hand-edited ones, and PLR has no place for them. The converter only needs to generate what Venus writes for freshly placed labware.

The rules as code

venus_rules.py (sketch)
TRACK_WIDTH = 22.5


def rail_location(site_id):
  """'6T-24' -> (617.5, 63, 100); 'M' marks a negative rail ('6T-M3' -> rail -3)."""
  m = re.match(r"(\d+)T-(M?)(\d+)$", site_id)
  rail = -int(m.group(3)) if m.group(2) else int(m.group(3))
  return 100 + (rail - 1) * TRACK_WIDTH, 63.0, 100.0


def a1_offset(rck):
  """Well A1 relative to the rack's front-left corner. BndryX/BndryY locate the front-left well."""
  rows = int(rck.get("Rows") or 0) or 1
  return float(rck["BndryX"]), float(rck["BndryY"]) + (rows - 1) * float(rck.get("Dy") or 0)


def rack_tform(corner_x, corner_y, rck):
  dx, dy = a1_offset(rck)
  return corner_x + dx, corner_y + dy                        # -> TForm.3.X / TForm.3.Y


def rack_corner(tform_x, tform_y, rck):
  dx, dy = a1_offset(rck)
  return tform_x - dx, tform_y - dy


def stack_z(site_z, racks_bottom_up):
  """Z of each rack in a stack on one site: each sits on the one below plus that one's StackHt."""
  z, out = site_z, []
  for rck in racks_bottom_up:
    out.append(z)
    z += float(rck.get("StackHt") or 0)
  return out


def lid_tform(plate_corner_x, plate_corner_y, rck, lid):
  """Lid corner, centred on the plate footprint. (Lid Z: no rule yet.)"""
  return (plate_corner_x + (float(rck["Dim.Dx"]) - float(lid["Dim.Dx"])) / 2,
          plate_corner_y + (float(rck["Dim.Dy"]) - float(lid["Dim.Dy"])) / 2)


def row_name(r):
  s = ""
  while r:
    r -= 1
    s = chr(65 + r % 26) + s
    r //= 26
  return s


def default_sequence(labware_id, rck):
  """What Venus writes for a rack with DefSeqValid 1: every position, column-major."""
  rows, cols = int(rck.get("Rows") or 0), int(rck.get("Columns") or 0)
  if not rows or not cols:                                   # troughs, tools: 1..HoleCnt
    names = [str(i) for i in range(1, int(rck.get("HoleCnt") or 1) + 1)]
  elif rck.get("IX.Index") == "1":                           # A1, B1 ... H1, A2 ...
    names = [f"{row_name(r)}{c}" for c in range(1, cols + 1) for r in range(1, rows + 1)]
  else:                                                      # 1, 2 ... numbered down the columns
    names = [str((c - 1) * rows + r) for c in range(1, cols + 1) for r in range(1, rows + 1)]
  return {"Name": labware_id, "ReadOnly": "0", "Items": [(labware_id, n) for n in names]}

Names

  • Carriers and Hamilton tip racks: 29 PLR factories carry Hamilton name: 'X' in their docstring (e.g. PLT_CAR_L5AC_A00 → hamilton_plate_carrier_L5_ac, HT → hamilton_96_tiprack_1000uL); others are named after the Venus name. Rack files add an orientation suffix (HT_L.rck).
  • Other labware: most of the 284 definitions in the test set have no PLR equivalent by name. Building a PLR resource straight from the .rck (rows, columns, pitch, boundary, size, well file) covers them all, and is checkable with the A1 rule.

Round-trip test plan

Test skeleton

tests/test_roundtrip.py
import pathlib

import pytest
from pylabrobot.resources import Deck

# venus_lay is the converter module to be written; these are its planned entry points.
from venus_lay import (
  read_lay, write_lay, footer_ok, lay_to_plr, plr_to_lay,
  normalize_lay, normalize_plr, default_sequence, rule_report,
)

LAYOUTS = sorted(pathlib.Path("fixtures/lay").glob("*.lay"))     # binary, as found
DECKS = sorted(pathlib.Path("fixtures/plr").glob("*.json"))      # generated PLR decks


@pytest.mark.parametrize("path", LAYOUTS, ids=lambda p: p.stem)
def test_t0_read_and_checksum(path):
  assert footer_ok(path.read_bytes())
  read_lay(path)


@pytest.mark.parametrize("path", LAYOUTS, ids=lambda p: p.stem)
def test_t1_write_is_lossless(path):
  assert write_lay(read_lay(path)) == path.read_bytes()       # footer recomputed identically


def test_t2_rules_hold_on_test_set():
  report = rule_report(LAYOUTS)                               # counts per rule, exceptions by name
  assert report.carrier_on_rail.failures == []
  assert report.rack_on_site.failures <= KNOWN_NUDGES         # listed, not just counted
  assert report.stack_step.failures <= KNOWN_STACK_EXCEPTIONS


@pytest.mark.parametrize("path", LAYOUTS, ids=lambda p: p.stem)
def test_t3_roundtrip_lay_plr_lay(path):
  lay = read_lay(path)
  again = plr_to_lay(lay_to_plr(lay))
  assert normalize_lay(again, sequences=False) == normalize_lay(lay, sequences=False)
  for rack in again.racks_with_default_sequence():
    assert again.sequence(rack.id) == default_sequence(rack.id, rack.definition)


@pytest.mark.parametrize("path", DECKS, ids=lambda p: p.stem)
def test_t4_roundtrip_plr_lay_plr(path):
  deck = Deck.load_from_json_file(str(path))
  again = lay_to_plr(read_lay(write_lay(plr_to_lay(deck))))
  assert normalize_plr(again) == normalize_plr(deck)
